Maki (Dog Character)

A stylized quadruped character developed through modeling, manual retopology, UV unwrapping and hand-painted texturing. The final mesh was designed for rigging and animation.

01

Overview

This project focuses on creating a stylized character with readable proportions, clean topology and a production-ready workflow. The character was modeled and retopologized in Blender, then textured by hand in 3DCoat.

Role

02

Turnaround

Front, side and back views used to present the character proportions, silhouette and texture distribution.

03

Topology

Manual retopology designed with continuous edge flow around the eyes, muzzle, shoulders and deformation areas.

04

UV Layout

The UVs were manually unwrapped to keep the main character surfaces readable and to provide enough space for hand-painted textures.

  • Manual UV unwrapping
  • Organized UV islands
  • Hand-painted texture workflow
  • Prepared for animation production
