Christmas Project.

A stylized holiday scene created during my internship at Cloud 10 Studio, featuring three original dinosaur characters developed for a festive cinematic composition.

The project focused on character modeling, look development, environment assembly, lighting and final rendering.

PROJECT

Stylized Character Scene

The scene was designed as a playful Christmas environment built around three stylized dinosaur characters. Each character was created with a distinct silhouette and personality while maintaining a consistent visual language across the collection.

The final composition combines warm fireplace lighting, colorful decorative lights and holiday props to create a cozy and narrative driven render.
